### "I want to know what to improve next"
1. Check [ROADMAP.md](ROADMAP.md) (task checklists by phase)
2. Or read [.claude/instructions/katyps5-improvements.md](.claude/instructions/katyps5-improvements.md) (decision matrix)

### "I found a bug"
1. See [CONTRIBUTING.md](CONTRIBUTING.md) Bug Reports section
2. Check [ROADMAP.md](ROADMAP.md) Ongoing Maintenance section
3. Report on [GitHub Issues](https://github.com/erickson558/KatyPS5/issues)

1. Read [SECURITY.md](SECURITY.md)
2. Follow responsible disclosure process (do NOT open public issue)
